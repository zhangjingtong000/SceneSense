# 单相机遮挡后重识别：可落地方案

## 一、先把病因说准

75% → 69% 不是"外观模型不够强"，是三个结构问题叠加：

1. **绝对阈值**。OSNet 在 MSMT17 上学到的特征，换到逆光/夜间/低机位场景，相似度分布整体平移。任何 `cos < 0.35` 式阈值只在一个场景成立。
2. **逐帧贪心**。遮挡恢复本质是低证据决策，逐帧匈牙利匹配没有回看和延迟机制，错了就永久错。
3. **特征被当标量用**。单帧或 EMA 得到一个向量，没有质量权重、没有多模态、没有时间维度。

下面按"改用法而非换模型"的原则给方案。

## 二、外观特征：改用法

**1. 分数归一化，取代绝对阈值（最高优先）**

每次检索时，对候选分数集合做 z-norm 或中位数-MAD 归一化，再按目标误匹配率取分位数作为门限。这是生物特征验证的标准做法，目的是让"跨场景阈值"变成"场景内相对排序"。

- 收益：直接针对换场景崩。
- 成本：约 50 行。
- 验证：留一场景后阈值不再需要逐场景重调。

补充：开放集 ReID 的分数校准近期有系统工作（无训练、校准后 FNIR 绝对降低 8.8%），但它是 face/gait/shape 多模态融合，思路可迁移、不能直接套用 → [arXiv:2610.07366](https://arxiv.org/abs/2610.07366)（较新，未核实细节）。

**2. Tracklet 级聚合 + 质量加权**

轨迹内帧特征用**中位数**聚合（均值会被遮挡帧拖偏），权重 = 检测置信度 × 框高 × 非边缘截断 × 遮挡估计。只在 confirmed track 上入 gallery，遮挡帧不更新。

- 收益：多帧聚合优于单帧是文献共识；中位数抗离群属工程经验，未核实具体数字。
- 成本：低。
- 验证：mean / median / 加权三组消融。

**3. 多原型 gallery + 时间衰减**

一个身份保留 3–5 个聚类中心，查询分取到各原型 top-k 均值。应对光照、姿态、外套变化。

- 收益：视频 ReID 标准做法，长时驻留下收益更大。
- 成本：低。
- 验证：按驻留时长分层统计。

**4. 遮挡感知特征**

只对上半身/头部池化，或用人体解析掩码取可见区域。

- 收益：遮挡 ReID 主线（PGFA、HOReID 一类）。
- 成本：中，需引入 pose/parsing 模型（+10~20ms/帧）。
- 验证：遮挡帧子集单看。

**5. 特征白化**

每段视频估计特征协方差做 PCA 白化，再算余弦。原理上直接消除分布漂移，公开对照数据未核实。成本极低。

## 三、轨迹级推理：收益最大

**6. 全局轨迹关联（AFLink + GSI）**

把在线轨迹当节点，做轨迹间关联与断轨拼接。StrongSORT 的 AFLink 用纯时空（不用外观）做全局连接，GSI 用高斯过程回归补断轨，每帧仅 +1.7ms / +7.1ms，MOT17/20/DanceTrack 达 SOTA。

- 收益：最对口"遮挡后接回"，且**无需标注、无需训练**。
- 成本：中（需缓存轨迹段）。
- 验证：IDs、IDF1 直接对比。

→ [arXiv:2202.13514](https://arxiv.org/abs/2202.13514) ｜ [代码](https://github.com/dyhBUPT/StrongSORT)

**7. 延迟决策 + best-k 多假设**

新轨迹先攒 10~15 帧高质量特征，再与丢失轨迹库批量匹配；不确定时保留 top-k，N 帧后再定。

- 收益：把单帧低证据变成多帧高证据。
- 成本：中。
- 验证：扫描"重现后第几帧匹配"的曲线找拐点。

## 四、几何与尺寸先验

**8. 单应性 + 地面平面马氏距离**

标 4 个地面点求单应，脚点映射到地面平面，用 Mapped Mahalanobis Distance 代替 IoU，投影不确定性自然进入协方差。UCMCTrack 仅靠运动线索在 MOT17/20/DanceTrack/KITTI 达 SOTA。

- 收益：门控大小随真实运动不确定性自适应，且物理合理（人不会瞬移）。
- 成本：低，一次标定管一个摄像头。
- 验证：换场景时门控不再需要逐场景调 IoU 阈值。

→ [arXiv:2312.08952](https://arxiv.org/abs/2312.08952) ｜ [代码](https://github.com/corfyi/UCMCTrack)

**9. 高度与速度方向作弱线索（training-free）**

把 bbox 高度状态、置信度、速度方向作为弱线索进代价矩阵。Hybrid-SORT 证明这三项可插拔地提升 5 个不同 tracker，无需训练，在密集遮挡场景收益最明显。

- 收益：外观失效时的主要补充。
- 成本：几十行代价项。
- 验证：按人群密度分桶。

→ [arXiv:2308.00783](https://arxiv.org/abs/2308.00783) ｜ [代码](https://github.com/ymzis69/HybridSORT)

**10. 尺度一致性硬约束**

同一人相邻深度上框高应连续（h ∝ 1/深度），高度跳变 >40% 的候选直接降权；从画面边缘消失的目标只应从边缘或遮挡物后方重现。

## 五、时序与不确定性

**11. 观测中心重更新（ORU）**

标准 Kalman 在无观测期信任先验，误差累积，恢复时位置漂移。OC-SORT 用虚拟轨迹在遮挡期修正滤波参数，700+ FPS 修复遮挡鲁棒性。

- 收益：直接对应"遮挡 0–2 秒后预测失效"。
- 成本：低，改 update 逻辑即可。
- 验证：按遮挡时长分层。

→ [arXiv:2203.14360](https://arxiv.org/abs/2203.14360) ｜ [代码](https://github.com/noahcao/OC_SORT)

**12. 不确定性驱动的门控与拒识**

协方差随丢失时长增长 → 外观权重上界随之收紧；最高分低于该场景分数分布分位数时**拒绝匹配、新建 ID**，而非强行归并。误拆可修复，误并不可。

- 成本：低。
- 验证：false merge / false split 比值曲线。

**13. 触发时机**

不要每帧检索。触发 = 丢失 ≥N 帧 ∧ 外观质量分达标 ∧ 时空门通过；新轨迹稳定后回看历史（双向关联）。

## 六、明确不适用

- **多相机/跨镜 ReID、相机拓扑**：单相机无对象。
- **3D 重建、多视角三角化**：不必要，4 点单应即可拿到地面约束，成本差两个数量级。
- **端到端训练/微调 ReID**：无标注。无监督域自适应虽有效，但需训练管线，收益不确定，不作为首发。
- **换更大 ReID 模型（TransReID/CLIP-ReID/SOLIDER）**：域偏移不会因模型变大消失，1920 下推理成本还上升。
- **人脸、步态**：监控分辨率/侧脸/任意视角下不可靠。
- **全量 MHT**：组合爆炸，best-k 近似够用。

## 七、验证方法（比方案更易出错）

1. **先给 75% 装置信区间**。7 场景 × 300 帧，遮挡事件可能只有几十个，bootstrap 后 75% 与 69% 很可能不显著。
2. **必须留一场景（LOSO）**：6 个定参、第 7 个测，轮换取均值，禁止在测试场景调参。
3. **分层指标**：按遮挡时长（0–0.5/0.5–1/1–2s）和密度分桶，报恢复率 + IDF1 + IDs。
4. **单变量消融**，每加一个组件跑一次 LOSO。

## 八、最值得先做的两件事

**① 分数归一化 + 延迟的 tracklet 级关联。** 唯一直接针对"换场景就崩"的改动：归一化让阈值跨场景可比，延迟让遮挡恢复从单帧低证据变多帧高证据。不改模型、不训练，2–3 天。

**② 单应性地面平面 + 马氏距离门控。** 把位置从像素搬到物理空间，门控由真实运动不确定性决定，而不是手调的 IoU 阈值——第二个"消除调参自由度"的杠杆。1 周内。
