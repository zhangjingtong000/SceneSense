# SceneSense 有界播放与实体高亮设计

## 目标

修正实体栏和事件入口的播放逻辑，使用户能够直接查看目标实体或事件对应的有效帧区间，并让实体高亮稳定、清晰、不干扰基础检测框刷新。

本轮只修改前端交互。人物遮挡融合、速度判断、Agent 协议、WebSocket 数据格式和后端检测结果均保持不变。

## 播放状态

前端维护一个可选的播放区间状态：

```js
playbackRange = null
// 或
playbackRange = { startFrame, endFrame, sourceType, sourceId }
```

`playbackRange` 为 `null` 时，播放器按完整视频播放。存在区间时，播放器最多播放到 `endFrame`，到达末帧后自动暂停并停留在末帧。

点击普通播放键时清除当前区间限制，从当前帧继续播放完整视频。

## 实体栏交互

实体栏主体点击行为：

1. 选中该实体并开启高亮。
2. 跳转到该实体的 `first_seen_frame`。
3. 设置播放区间为 `[first_seen_frame, last_seen_frame]`。
4. 自动开始播放。
5. 到达 `last_seen_frame` 后自动暂停并停留在末帧。

每个实体栏增加“仅高亮”独立按钮：

1. 点击按钮只切换该实体的高亮状态。
2. 不跳转视频。
3. 不改变当前播放或暂停状态。
4. 不改变当前播放区间。
5. 重复点击已选中实体的“仅高亮”按钮会关闭高亮。

重复点击当前已选中的实体栏主体会关闭高亮，但仍重新执行该实体区间的跳转和播放。

## 事件交互

事件热力块和右侧事件列表条目采用完全一致的行为：

1. 跳转到事件开始帧。
2. 设置播放区间为 `[frame_start, frame_end]`。
3. 自动开始播放。
4. 到达事件结束帧后自动暂停并停留在末帧。

## 高亮渲染

新增独立透明 Canvas，叠加在基础视频 Canvas 上方。基础视频 Canvas 继续负责 JPEG 帧、普通检测框和骨架；高亮 Canvas 只负责当前选中实体。

高亮采用静态高对比样式：

- 半透明强调色填充；
- 外层白色描边；
- 内层高饱和强调色描边；
- 固定实体标签；
- 不使用闪烁动画。

每次视频帧变化时清空高亮 Canvas，再根据当前帧的实体检测框重新绘制。若当前帧不存在该实体，则保留选中状态但不绘制过期框。

## 测试

前端契约测试覆盖：

- 实体栏主体使用 `first_seen_frame`，不再使用 `last_seen_frame` 作为跳转目标；
- 实体栏主体触发实体有界播放；
- “仅高亮”按钮阻止事件冒泡，并且不触发跳转或播放；
- 事件热力块与事件列表条目触发事件有界播放；
- 有界播放到达结束帧后自动暂停；
- 普通播放键清除区间限制；
- 页面存在独立高亮 Canvas。

浏览器验证覆盖：

- 页面加载无控制台错误；
- 上传视频后实体栏主体点击会从首次出现帧开始播放；
- “仅高亮”不会改变当前帧；
- 热力块和事件列表点击会自动播放并在各自末帧停止；
- 实体高亮稳定且醒目，无动画闪烁。
